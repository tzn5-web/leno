# EVO Launcher / K2401_JT
Preview Android 10 HOME app. Left panel: **navigation DEMO** with external Google Maps launch. Top right: YouTube Music **MediaSession controller** when Notification Access enabled; not an embedded app. Bottom right: Torque-style gauges: **SIMULARE** only in emulator, otherwise **OBD NECONECTAT** (no fabricated live values). Other screens: Music, Navigation, Car, Apps, Settings. No animation loop, no root, no ROM changes, no MCU or CAN write.
Build via Gradle 8.11.1, Android Gradle Plugin 8.5.2, Java 17, SDK 35, min API 26 / target 28. Run GitHub Actions workflow to compile debug APK and smoke-test 1280x720 Android 10 emulator.
The desired *actual* half-screen Google Maps requires official Maps SDK + enabled billing/API key or validated compatible multiwindow; full native YouTube Music activity cannot be embedded arbitrarily. Torque live data requires real Bluetooth OBD adapter and ECU validation. DO NOT set as default launcher on a driving vehicle until OEM radio, reversing camera, buttons, standby and CANBUS are checked on actual head unit.
