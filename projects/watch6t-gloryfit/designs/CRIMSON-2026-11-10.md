Source: the user's latest black/red/silver concept image selected in the conversation (not the earlier RED4 image). The private source artwork, stock GloryFit BIN, resulting BIN and recovery bundle are held in the delivered private ZIP, not checked into this public repository.

## Offline build result

- Target: iHunt Watch6T-D123, GloryFit native 240×240 RGB565 big-endian row-major.
- Native face ID: `189801`; original 22 element types and all frame counts retained.
- Stock BIN: 343,944 bytes.
- CRIMSON BIN: **381,046 bytes**, SHA256 `97a54ca6c1a7dadfa1e2fded5cc9bb0bc2f0818b47c7092502b76a451b4b5847`.
- Native CRC32, file pointers, geometry, table sentinel, preserved source metadata and 1 MiB size gate verified.
- **8/8 offline tests passed**, including proof that clock digits are not baked into the live background and that picture preview matches encoded native RGB565.
- Former weather, distance and original skin widgets are disabled as transparent frames without deleting their table records.

## Functional scope / limitations

The face reuses native dynamic sprite families for hour/minute, calendar, pulse, steps, calories, and numeric battery. The analog hands, ECG artwork, battery-icon bars and `SpO2 --` are static and do not claim live readings.

**No hardware watch display confirmation**. The private Windows installer is intended to use the pinned owner BLE uploader at commit `b0ff37ca2748acf05081c764cdffb8e79163cc14` with explicit confirmation for the `26 02` slot-write command and a stock BIN rollback. An unsuccessful transfer must not be retried automatically; use an official GloryFit watchface for recovery. Do not use OTA/DFU firmware endpoints.

This note documents an offline-tested build, not a confirmed physical installation.
