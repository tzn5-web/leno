# Watch6T HOLO V2 — binary patch audit (2026-11-09)

## Source material
Owner-provided GloryFit cached dial: `D1898001.bin`, 343,944 bytes, 240 × 240 px, 22 image/element records. It is NOT committed because it contains third-party proprietary art.

## New decoding finding
The payload is **not uniformly row-major**:
- Both 240 × 240 images (IDs 10 preview and 17 live background) decode as big-endian RGB565 row-major.
- The small glyph/weather frames decode as big-endian RGB565 **column-major**. Decoding as row-major causes false horizontal corruption. After correcting the layout, the 14-frame number family renders recognizably (0–9 at frames 3–12), as do day/month names and 16 weather icons.
- The 14-frame image families are not evidence that the numeric measurement itself has been read from the device; they are candidate sprites to be selected by firmware.

## V2 prototype
`Build-HOLO-BIN-V2.py` constructs a candidate `.bin` from the unmodified original, plus the exact selected HOLO illustration.

Only two fixed 240 × 240 image payloads are replaced (record IDs 10 and 17). The **other 20 element payloads, 22 record definitions, offsets, file identifier, 240 × 240 dimensions and declared payload size remain untouched**. The rebuilt file is still **343,944 bytes** and the CRC32 at offset 8 is recalculated and verified.

This preserves the original dynamic image *slots*, but does **not** prove that those slots will be evaluated on a particular firmware, nor that the new background avoids all text collisions in the actual rendered face. The local PNG preview is an offline demonstration, not a screenshot.

## Actual outputs (private)
- `D1898001_HOLO_V2_OFFLINE_UNTESTED.bin`: 343,944-byte candidate.
- `D1898001_ORIGINAL_BACKUP.bin`: untouched fallback bytes.
- `manifest.json`: SHA256 and CRC32 proof, source and candidate.
- `HOLO_V2_preview_SIMULATION.png`: offline composite, approximate device presentation.
- `Watch6T-Cache-Gate.ps1`: read-only cache probe, no BLE/write commands.
- `test_v2.py`: asserts record table unchanged and non-background payloads unchanged.

These proprietary graphics/binaries are distributed privately to the user in this conversation, not in the public GitHub repository.

## Remaining blocker
The stock cached BIN's relation to the active watch face and to the model firmware `RB235DCEV004137` has **not** been confirmed. The APK's upload code has identifiable calls, but the full online-watch-face download/selection/transfer handshake is not verified. Do not install this BIN through firmware update, raw BLE or by replacing an active file. Use the read-only cache gate before any install tests.
